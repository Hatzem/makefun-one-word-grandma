One Word From Grandma: this entry writes exactly one word — the single word
a grandma would text about AI — to `/output/entry.txt`. The word is
"contraption": warm, a little baffled, funny on its own, and tied to machines
rather than anything else. It is the word she uses for a clever device she
does not quite understand, which is exactly how she would greet AI.

## Run it

```sh
python3 main.py
```

It creates `/output` if needed and writes the word to `/output/entry.txt`.
